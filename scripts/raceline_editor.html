How

Map — drag a handle to move it; shift-drag moves 10× finer. Drag a box over empty track to select several handles (shift adds, ctrl-click toggles one, ctrl+A all); dragging any selected handle moves them together. Arrows nudge the selection, [ ] step through handles, Del removes the selection. Double-click the line to add a handle.
Wheel zooms at the cursor; right-drag, middle-drag or space+drag pans; F fits, +/− zoom.

Profile — drag to pin a speed cap; double-click a pin to clear it. Wheel zooms the distance axis, right-drag pans it.

P plays the race replay, N toggles normal-only dragging.
